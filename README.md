# TB Monitoring Overview Demo

[Open the demonstration](https://xhuan618.github.io/tb-monitor-overview-demo/)

A frontend-only TB monitoring demonstration with Chinese, English and Indonesian interfaces, deterministic simulated data, date filtering, province/city selection, charts and briefing dialogs.

This repository contains static release files only. No backend, authentication service, database, credentials or original project source is included.

All health figures and recommendations are synthetic demonstration content, not medical advice or an operational surveillance report. The simplified historical 34-province Indonesia boundaries are reused from the supplied project's GADM 4.1 data and are not a current authoritative administrative map. Original asset and geographic-data terms remain applicable.
